# indri: scalable additive genetic covariance estimation

Fits a multivariate animal model on many small trait subsets and
reassembles the subset estimates into one positive semi-definite
additive genetic covariance matrix. Start with
[`fit_G()`](https://diogro.github.io/indri/reference/fit_G.md);
`NOTES.md` in the repository root describes the estimator, the engine
contract and the defaults.

## References

Meyer, H. V., Casale, F. P., Stegle, O., and Birney, E. (2018). LiMMBo:
a simple, scalable approach for linear mixed models in high-dimensional
genetic association studies. bioRxiv, preprint.
[doi:10.1101/255497](https://doi.org/10.1101/255497)
