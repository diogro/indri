indri

Additive genetic covariance matrices for large trait sets, and the genome scans they drive, in R.

Source on GitHub Changelog Validation status Issues

indri estimates the additive genetic covariance matrix G (traits × traits) without fitting one giant multivariate animal model. It splits the traits into many small, overlapping subsets, fits a small animal model on each, and reassembles the estimates into a single positive semi-definite matrix, following LiMMBo. The per-subset fit is pluggable (a Bayesian sampler or a REML engine), and every engine gives per-entry uncertainty.

The assembled G and residual covariance E then drive genome-wide association scans: one multi-trait test per SNP across all traits, or trait-by-trait tests, in a linear mixed model, with optional dominance effects, permutation p-values and genotype-by-environment tests.

Vignettes

Four worked analyses of the nine weekly weight gains of the LG/SM F3 mice (lgsm_f3) that ship with the package. They were precomputed, because the fits take up to half an hour.

Estimating G for many traits: engines and priors

Genome scans for many traits: additive and dominance effects

Multi- and single-trait scans, thresholds and permutations, dominance, and effects across the growth curve.

G from locus effects

Quick start

library(indri)

# The nine weekly weight gains of the LG/SM F3 mice, with sex, cohort and
# litter sizes as fixed effects.
traits <- lgsm_traits$growth
d <- lgsm_f3[stats::complete.cases(lgsm_f3[c(traits, "LSB", "LSW")]), ]
Y <- as.matrix(d[traits]); rownames(Y) <- d$ID
X <- model.matrix(~ SEX + factor(COHORT) + LSB + LSW, d); rownames(X) <- d$ID
A <- lgsm_A[rownames(Y), rownames(Y)]

fit <- fit_G(Y, X = X, A = A, engine = "sommer")

fit          # summary
fit$G        # G, in the units of Y
fit$corrG    # genetic correlations

The first vignette walks through this fit with all three engines; the README has a self-contained simulated example.
